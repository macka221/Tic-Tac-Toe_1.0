# Tic Tac Toe v1.0.1

## Description

This is a revision of a problem given to me in college. I was tasked
with building a simple Tic Tac Toe game in C++. The requirements
were very lackadaisical, so I decided to make a simple console-based
game that could be played without input validation or error handling.
A v2 of this game can be found at [Tic-Tac-Toe v2](https://github.com/macka221/Tic_Tac_Toe_2.0). As of now v2 has not
been edited to meet my current standards, and will be revised after
this is completed.

## Requirements

- Without the use of external libraries (aside from the string library)
  create a tic-tac-toe game that can be played in the console endlessly
  until a user decides to quit.
- Input validation is not necessary as this is a refresher on C++ basics.
- Error handling is also not required.
- Testing is required.
- Must be a standard 3x3 grid that looks like the following:

```shell
  1 | 4 | 7
 ---+---+---
  2 | 5 | 8
 ---+---+---
  3 | 6 | 9
```

- After each game the board should reset.
- A score should be kept for all users and displayed after each game.
- Each player should be greeted with their first name during each turn.
